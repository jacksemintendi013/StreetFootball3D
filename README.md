# FIFA Mundial 🌍⚽

Un gioco di calcio open-world realistico ispirato a FIFA Street, giocabile su **mobile** e **PC**.

## 🎮 Caratteristiche Principali

- **Open World Urbano**: Esplora città realistische e gioca ovunque
- **Gameplay Realistico**: Fisica realistica, animazioni fluide, controlli intuitivi
- **Partitelle Dinamiche**: Sfida NPC in partite 1v1, 2v2, 3v3
- **Dribbling Avanzato**: Sistema di dribbling con comandi gesto e controller
- **Abilità Personaggio**: Sblocca trucchi, mosse speciali e skill
- **Multiplayer Online**: Sfida amici in modalità PvP
- **Progressione**: Carriera, livelli, premi e skin personalizzate
- **Cross-Platform**: Gioca da mobile (iOS/Android) e PC (Windows/Mac/Linux)

## 🛠️ Tecnologie Utilizzate

- **Engine**: Unity 2023 LTS
- **Linguaggio**: C#
- **Networking**: Photon PUN2 / Mirror
- **Fisica**: Built-in Physics 3D
- **Mobile**: Unity Mobile Tools
- **VCS**: Git + GitHub
